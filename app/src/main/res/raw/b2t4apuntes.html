Tema 4. Sistemas operativos

Un sistema operativo es el software base que actúa como intermediario entre el hardware, las aplicaciones y el usuario. Su función principal es gestionar los recursos del equipo y ofrecer servicios comunes para que los programas puedan ejecutarse de forma segura y ordenada.

Entre sus responsabilidades se encuentran la administración de procesos, memoria, ficheros, dispositivos de entrada/salida, usuarios, permisos y comunicaciones de red.

Funciones principales

  • Gestión de procesos: crea, planifica, suspende y finaliza programas en ejecución.
  • Gestión de memoria: asigna memoria principal y utiliza memoria virtual cuando es necesario.
  • Gestión de almacenamiento: organiza ficheros y directorios mediante sistemas de archivos.
  • Gestión de dispositivos: coordina periféricos a través de controladores o drivers.
  • Seguridad: controla autenticación, permisos, aislamiento y auditoría.
  • Interfaz de usuario: proporciona consola, entorno gráfico o ambas opciones.

Núcleo o kernel

El kernel es la parte central del sistema operativo. Se ejecuta con privilegios elevados y controla el acceso al hardware. Las aplicaciones no acceden directamente a los dispositivos, sino que solicitan servicios al núcleo mediante llamadas al sistema.

Tipos de kernel

  • Monolítico: integra la mayoría de servicios en el núcleo. Es eficiente, pero un fallo interno puede afectar a todo el sistema.
  • Microkernel: deja en el núcleo solo funciones esenciales y mueve servicios a espacio de usuario. Mejora el aislamiento.
  • Híbrido: combina características de ambos enfoques, buscando rendimiento y modularidad.

Procesos, hilos y planificación

Un proceso es un programa en ejecución con su propio espacio de memoria y recursos asociados. Un hilo es una unidad de ejecución más ligera dentro de un proceso; varios hilos pueden compartir memoria y recursos del mismo programa.

La planificación decide qué proceso o hilo usa la CPU en cada momento. En sistemas multitarea, esta decisión permite que varias aplicaciones parezcan ejecutarse simultáneamente.

  • FCFS: atiende procesos por orden de llegada.
  • Round Robin: asigna turnos de CPU de duración fija.
  • Prioridades: ejecuta antes los procesos considerados más importantes.
  • SJF: favorece los trabajos con menor tiempo estimado de ejecución.
Estados típicos: nuevo, preparado, en ejecución, bloqueado y terminado.

Memoria principal y memoria virtual

El sistema operativo asigna memoria RAM a los procesos y evita que unos programas accedan indebidamente a la memoria de otros. Cuando la RAM no es suficiente, puede utilizar memoria virtual, apoyándose en disco para ampliar el espacio disponible.

  • Paginación: divide la memoria en páginas de tamaño fijo.
  • Segmentación: organiza la memoria en segmentos lógicos como código, datos o pila.
  • Swap: mueve datos entre RAM y disco para liberar memoria principal.
  • Protección de memoria: impide accesos no autorizados entre procesos.

Un uso excesivo de swap degrada el rendimiento porque el acceso a disco es mucho más lento que el acceso a RAM.

Sistemas de archivos

Un sistema de archivos define cómo se nombran, almacenan, organizan y recuperan los datos en un dispositivo de almacenamiento. También gestiona metadatos como tamaño, fechas, propietario y permisos.

  • FAT32: compatible con muchos sistemas, pero limitado en tamaño máximo de archivo.
  • exFAT: útil en memorias externas y tarjetas SD por su compatibilidad.
  • NTFS: habitual en Windows, con permisos, compresión y journaling.
  • ext4: común en Linux, robusto y con journaling.
  • APFS: usado en sistemas Apple modernos, optimizado para almacenamiento flash.

Entrada/salida y controladores

Los dispositivos físicos se gestionan mediante drivers, que traducen las órdenes del sistema operativo a instrucciones específicas del hardware. El sistema operativo coordina interrupciones, búferes, colas de E/S y acceso concurrente a los dispositivos.

  • Interrupciones: señales que informan a la CPU de un evento de hardware.
  • Búfer: memoria temporal que suaviza diferencias de velocidad entre dispositivos.
  • Spooling: cola de trabajos, frecuente en impresión.
  • Plug and Play: detección y configuración automática de hardware.

Usuarios, permisos y seguridad

Los sistemas operativos multiusuario separan cuentas, grupos, privilegios y recursos. El objetivo es aplicar el principio de mínimo privilegio: cada usuario o proceso debe disponer solo de los permisos necesarios.

  • Autenticación: verifica la identidad mediante contraseña, certificado, token o biometría.
  • Autorización: decide qué operaciones puede realizar una identidad autenticada.
  • Permisos: lectura, escritura y ejecución en ficheros y directorios.
  • Auditoría: registro de eventos relevantes para seguridad y diagnóstico.

Tipos de sistemas operativos

Clasificación habitual

  • Monousuario y multiusuario: según permitan una o varias cuentas trabajando en el sistema.
  • Monotarea y multitarea: según ejecuten una o varias tareas de forma concurrente.
  • Tiempo compartido: reparten CPU entre usuarios o procesos interactivos.
  • Tiempo real: garantizan respuesta dentro de límites temporales estrictos.
  • Distribuidos: coordinan varios equipos como si fueran un sistema único.
  • Embebidos: diseñados para dispositivos concretos, con recursos limitados.

Ejemplos actuales

  • Windows: extendido en escritorio y entornos corporativos.
  • GNU/Linux: habitual en servidores, supercomputación, desarrollo y sistemas embebidos.
  • macOS: sistema de Apple basado en Unix.
  • Android: sistema móvil basado en kernel Linux.
  • iOS: sistema móvil de Apple con fuerte control del ecosistema.
